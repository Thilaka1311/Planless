# Planless Brand System

## 1. Brand Colors

Planless uses a simple three-color core palette:

### Primary — Planless Orange
HEX: `#FF6B2C`

Use for:
- Primary brand elements
- CTAs
- Important highlights
- Interactive emphasis
- Brand accents

### Background — Black
HEX: `#000000`

Use for:
- Main backgrounds
- Large visual surfaces
- Marketing backgrounds
- High-contrast compositions

### Accent — White
HEX: `#FFFFFF`

Use for:
- Primary text on dark backgrounds
- Icons
- Contrast elements
- Supporting visual accents

Do not introduce additional colors into the core brand palette unless explicitly approved.

---

## 2. Typography

Planless uses two primary fonts for its visual communication system.

### Bold / Display Font — Space Grotesk

Use Space Grotesk for:
- Headlines
- Large statements
- Hooks
- Section titles
- Important numbers
- Bold visual messaging
- Marketing headlines

The typography should feel:
- Bold
- Modern
- Clean
- Confident
- Simple

### Body Font — Inter

Use Inter for:
- Body copy
- Descriptions
- Captions
- Supporting text
- Labels
- Explanations
- UI-style copy

The typography should feel:
- Clean
- Readable
- Neutral
- Simple

---

## 3. Brand Wordmark

The Planless wordmark uses:

**Grand Hotel**

Grand Hotel is specifically for the Planless wordmark/logo.

Do not use Grand Hotel as the general body or headline font.

---

## 4. Visual Direction

Planless should generally feel:

- Social
- Young
- Simple
- Energetic
- Playful
- Confident
- Real-world
- Modern

The visual identity should avoid feeling:
- Corporate
- Formal
- Overly polished
- Generic SaaS
- Overly complicated

The core visual combination should strongly favor:

`#000000` background + `#FFFFFF` text + `#FF6B2C` brand emphasis.

When creating future Planless:
